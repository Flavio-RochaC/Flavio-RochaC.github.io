# Taberna do Goblin - Ludoteca (Landing Page)

landing page estática de uma ludoteca fictícia, desenvolvida com **HTML5** e **CSS3**.

## Estrutura de Arquivos

'''
boblin-taberna/
|
├ index.html → Página principal (página de destino)
├ obrigado.html → Página de agradecimento após envio do pedido
├ style.css → Estilo principal (importado por ambas as páginas)
└ README.md → Este arquivo
'''

## Recursos Utilizados

- **HTML5** semântico
- **CSS3** puro (flexbox, grid, media queries, parallax com 'background-attachment: fixed')
- **Font Awesome 6** (via CDN) - ícones e logotipo de dados
- **Google Fonts** - Cinzel (títulos) e Inter (corpo)
- **Imagens** - Fundo Hero e foto cliente, ambas baixadas e alocadas da pasta img.

## Seções da Página

1. **Cabeçalho fixo** - Logo com dois dados sobrepostos + menu de navegação com âncoras
2. **hero** - imagem de funco com efeito paralaxe e frase de destaque
3. **Benefícios** - 3 cartões responsivos com ícones
4. **Estilos de Jogos** - tags estilizadas (Party Games, Eurogame, etc.)
5. **Depoimento** - foto, nome do cliente e texto da analise (estático)
6. **Formulário de Pedido** - nome, telefone, endereço, tipo de reserva, jogo, forma de pagamento.
7. **Rodapé** - icones sociais, nome do projeto (Nome do aluno) e direitos autorais
